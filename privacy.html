このアプリについて

「madristats」は、YouTubeチャンネル「マドリー・スタッツ」の運営者が、自分で作った動画を自分のチャンネルにアップロードするための個人用ツールです。

利用するデータ

このアプリは、Googleアカウントでの許可を通じて、YouTube Data API の次の権限だけを使います。

  • 動画のアップロード、タイトル・説明文・サムネイルの設定（youtube.upload / youtube）

取得した認証情報は、運営者のパソコンの中にだけ保存され、外部のサーバーには送信しません。視聴者やほかのユーザーの個人情報は取得・保存・共有しません。

第三者への提供

取得したデータを第三者に販売・提供することはありません。

許可の取り消し

許可はいつでも Googleアカウントのサードパーティ接続の設定 から取り消せます。

YouTube 利用規約とGoogleプライバシーポリシー

このアプリはYouTube APIサービスを使用しています。YouTube利用規約、Googleプライバシーポリシーもあわせてご確認ください。
